## ✨ Características y Funcionalidades

1. **Guardar Contacto en 1 Clic**:
   - Botón principal que genera y descarga automáticamente el archivo estándar `Laura_Ramos_AUREA.vcf` (vCard 3.0).
   - Añade directamente a Laura Ramos en la agenda de **iPhone (Contactos de Apple)** y **Android (Contactos de Google)**.

2. **Acciones Directas Rápidas**:
   - **WhatsApp**: Inicia chat directo con mensaje de cortesía preconfigurado.
   - **Email**: Abre el cliente de correo preconfigurado para escribir a Laura.
   - **Llamar**: Conecta llamada telefónica directa.

3. **Herramientas de Difusión**:
   - **Modal de Código QR**: Genera en pantalla el QR de la tarjeta para que cualquier persona frente a ti pueda escanearla al instante con su cámara.
   - **Botón Compartir**: Integra la API nativa de compartir del sistema operativo o copia el enlace al portapapeles.

4. **Sustituir Iniciales "LR" por Foto**:
   - Por defecto muestra un monograma editorial de lujo con las iniciales `LR`.
   - Cuando quieras utilizar tu foto, guarda tu fotografía como `foto.jpg` en esta misma carpeta y descomenta la etiqueta `<img>` indicada en `index.html`.
